# QI Perfume Order Form

This project is a simple perfume ordering website built using HTML and CSS.

## Features

* Perfume product image
* Customer order form
* Delivery option selection
* Clean and simple design

## Technologies Used

* HTML
* CSS

## How to Use

1. Open the `index.html` file in a web browser.
2. Fill in the perfume order form.
3. Submit your order.
